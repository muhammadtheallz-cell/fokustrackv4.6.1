# FokusTrack v4.6.1 — Build Compatibility Patch

Patch ini memperbaiki kegagalan build yang dilaporkan dari deployment Vercel v4.6.0. Tidak ada fitur aplikasi yang dihapus.

## Perbaikan build

1. `src/context/AppContext.tsx`: tambahkan penegasan ulang bahwa `activities` dan `transactions` memang array setelah snapshot dinormalisasi. Ini menyelesaikan dua strict-nullability errors ketika TypeScript memeriksa properti JSON.
2. `src/utils/push.ts`: decoder VAPID public key sekarang mengembalikan `ArrayBuffer` konkret untuk `PushManager.subscribe()`, bukan `Uint8Array<ArrayBufferLike>` yang dapat mencakup `SharedArrayBuffer`.
3. Root dan companion server dipatok ke Node.js `22.x` agar versi runtime build konsisten di Vercel dan hosting Push.

## Validasi yang dilakukan pada patch

- TypeScript strict check terarah untuk `AppContext.tsx` dan `push.ts` lulus menggunakan TypeScript yang tersedia di lingkungan patch dengan deklarasi React sementara untuk memeriksa modul konteks.
- 21/21 unit tests lulus.
- Pemeriksaan sintaks JavaScript server dan Service Worker lulus.
- File konfigurasi JSON valid.
- Full dependency install dan `npm run build` belum dapat dijalankan di lingkungan patch karena akses npm registry mengalami DNS `EAI_AGAIN`. Jalankan `npm install` dan `npm run build` pada CI/Vercel untuk verifikasi build penuh.

## Deployment

Gunakan Node.js `22.x`, Build Command `npm run build`, Output Directory `dist`, dan Root Directory sesuai lokasi `package.json`.
