# FokusTrack v4.5 — Catatan Upgrade dan Pemeriksaan

## Ringkasan

v4.5 merupakan penyempurnaan langsung dari source `FokusTrack-v4.0-source.zip`. Struktur utama PWA dipertahankan: React + TypeScript + Vite, empat area utama (Beranda, Fokus, Kalender, Keuangan), penyimpanan lokal, serta server pendamping Web Push.

## Fitur baru dan perubahan timer fokus

- Menambahkan input durasi custom berupa jam dan menit.
- Batas durasi custom: minimum 1 menit, maksimum 12 jam (720 menit).
- Mengubah tampilan waktu otomatis menjadi `HH:MM:SS` untuk sesi yang dipilih berdurasi minimal satu jam. Format tetap stabil sampai sesi selesai, termasuk saat sisa waktu sudah kurang dari satu jam.
- Durasi custom tetap dipakai ketika sesi fokus dimulai dari aksi cepat Beranda.
- Aksi cepat Beranda tidak mengganti timer yang sedang berjalan atau dijeda; aplikasi diarahkan kembali ke layar Fokus.
- Memvalidasi durasi preset yang masuk ke state timer.
- Menghitung menit sesi manual menggunakan sisa waktu yang dibatasi ke rentang durasi timer; nilai sisa negatif atau melebihi durasi tidak membuat hasil menit menjadi tidak masuk akal.
- Menyimpan pilihan durasi, label sesi, sisa waktu, status berjalan, serta waktu akhir absolut di `localStorage`.
- Ketika aplikasi dimuat ulang, sisa waktu dihitung lagi dari deadline absolut. Jika deadline telah lewat saat aplikasi tertutup, sesi lengkap direkam satu kali ketika aplikasi dibuka kembali, menggunakan timestamp deadline.
- Target fokus harian dibatasi konsisten pada 10–720 menit, sama seperti validasi pengaturan saat data dimuat.
- Pesan selesai timer dibedakan antara sesi fokus dan sesi istirahat agar istirahat tidak keliru diklaim menambah streak.

## Pemeriksaan dan test

Tes otomatis pada helper timer:

1. Durasi minimum dan maksimum custom diterima.
2. Durasi kosong, negatif, pecahan, dan di atas batas ditolak.
3. Label durasi untuk menit dan jam diformat benar.
4. Jam digital beralih antara `MM:SS` dan `HH:MM:SS`.
5. Sisa waktu dihitung dari deadline absolut dan tidak pernah negatif.
6. Penyelesaian manual hanya menghitung menit penuh yang benar-benar dijalani.

Perintah pemeriksaan:

```bash
npm run test:focus
npm run audit:syntax
npm run build
```

## Catatan batasan platform

- Timer tetap dihitung akurat dengan waktu akhir absolut ketika tab berjalan atau saat aplikasi dibuka kembali.
- Browser tidak menjamin audio atau notifikasi timer tepat pada saat aplikasi benar-benar ditutup/dihentikan. Ketika aplikasi dibuka lagi setelah deadline, sesi dipulihkan dan dicatat, tetapi ini bukan pengganti alarm Android native.
- Push pengingat kegiatan tetap memerlukan HTTPS, browser yang mendukung Push API, izin notifikasi, server push yang aktif, dan koneksi internet.
- Data utama tetap lokal di perangkat. Sinkronisasi akun lintas perangkat belum ditambahkan di v4.5.

## Cara menguji durasi custom

1. Buka tab **Fokus**.
2. Tekan **Custom**.
3. Isi kolom Jam dan Menit, misalnya `1` jam dan `30` menit.
4. Tekan **Gunakan Durasi**. Tampilan timer harus menunjukkan `01:30:00`.
5. Mulai timer, pindah ke Beranda, lalu kembali ke Fokus. Timer harus tetap melanjutkan hitung mundur.
6. Muat ulang aplikasi saat timer berjalan. Sisa waktu harus dihitung ulang dari deadline yang disimpan.
7. Untuk uji pemulihan selesai, gunakan durasi uji singkat, tutup halaman melewati deadline, lalu buka kembali. Satu sesi fokus harus dicatat tanpa duplikasi.
