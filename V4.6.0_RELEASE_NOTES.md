# FokusTrack v4.6.1 — Build Compatibility Patch Release Notes

## Highlight

- Perbaikan hitung streak berdasarkan timestamp penyelesaian aktual.
- Perbaikan crash/loss path pemulihan sesi fokus dan reset total.
- Pengelolaan antrean alarm yang tidak membuang alarm berikutnya atau reminder dalam burst.
- Scheduler reminder foreground berbasis deadline terdekat.
- Penguatan validasi data, penyimpanan, reset, dan pemulihan snapshot.
